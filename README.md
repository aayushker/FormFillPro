# FormFillPro

FormFillPro is a browser extension that fills forms hassle free using your saved information. It streamlines the process by auto-detecting form fields (such as name, email, phone, and college) and populating them with the data you provide. You can also save multiple templates to easily switch between different sets of form data.

## Features

- **Automatic Form Filling:** Uses intelligent matching to detect form fields based on common field patterns.
- **Customizable Templates:** Save your form data as templates and reuse them whenever needed.
- **User-Friendly Interface:** An accessible popup provides options to fill, edit, import/export data, and manage templates.
- **Live Notifications:** Receive visual feedback when forms are auto-filled or data is saved.
- **Import/Export Support:** Easily backup or restore your autofill data and saved templates.
- **Cross-Browser Support:** Available for Chrome, Firefox, Edge, Opera, and other Chromium-based browsers.

## Installation

1. **Clone or Download the Repository**

    Download the project files from your repository.

2. **Load the Extension in Your Browser**

    ### For Chrome:
    - Navigate to `chrome://extensions/`
    - Enable **Developer mode** in the top-right corner
    - Click on **Load unpacked**
    - Select the project folder

    ### For Firefox:
    - Navigate to `about:debugging#/runtime/this-firefox`
    - Click on **Load Temporary Add-on**
    - Select any file in the project folder

    ### For Edge:
    - Navigate to `edge://extensions/`
    - Enable **Developer mode**
    - Click on **Load unpacked**
    - Select the project folder

3. **Set Up Your Data**

    - Click on the extension icon.
    - Use the **Edit My Info** button to enter your personal details.
    - Save your information to use for auto-filling forms.

## Usage

- **Fill a Form:**  
  Navigate to any webpage with a form, click the extension icon, and then use the **Fill Current Form** button. Your saved data will automatically populate the form fields.

- **Manage Templates:**  
  Use the **Add New Template** button to save your current autofill data as a template. You can later use, edit, or delete these templates directly from the popup interface.

- **Import/Export Data:**  
  Click the **Import Data** or **Export Data** buttons to backup or load your autofill data and templates.
